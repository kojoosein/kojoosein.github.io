Flight-Log Health Dashboard for ArduPilot

Personal project Developer In progress Aug 2026 – Present

I am developing a dashboard for reviewing ArduPilot flight logs and identifying potential aircraft health issues.

Personal project

The problem

Every flight I have debugged started the same way: scrolling a log by hand looking for the moment something changed. That is a task a computer should do. I am building the tool I wish I had had, using my own archive of real failures as the test set — if it cannot find the GNSS glitch I already know is in there, it is not working.

What I did

In-progress tool that ingests ArduPilot BIN/CSV flight logs and reports vibration levels, EKF innovations, GPS quality, battery and current draw, motor-output balance, commanded vs. actual attitude, failsafe events, and waypoint error — with automatic anomaly flagging. Built against a real corpus: the GNSS glitches, EKF resets, yaw imbalance, and thrust-loss warnings from three years of my own flight testing serve as the labeled cases.
