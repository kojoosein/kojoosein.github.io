Personal project Developer Sep 2026 – Present

A ROS and Arduino build to work fluently in the C++ side of the robotics stack, not just Python against a flight controller.

The problem

Most of my autonomy work so far has been Python against a flight controller. ROS is where the wider robotics world actually builds, and it is largely C++, so this project exists to close that gap on real hardware rather than in a tutorial.

What I did

  • Building a ROS based robotics project with Arduino microcontrollers handling low level sensing and actuation, to work fluently in ROS nodes and topics and in the C++ side of the robotics stack.
